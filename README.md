# Портфолио Ксении Пронозиной

Одностраничный сайт + админка для добавления работ.

- Сайт: `https://<твой-сайт>.vercel.app`
- Админка: `https://<твой-сайт>.vercel.app/admin`

## Как это устроено

```
index.html          ← сам сайт (дизайн, анимации, игра с наклейками)
data/projects.json  ← список работ (его правит админка)
data/site.json      ← тексты: обо мне, опыт, скиллы, услуги, контакты, финал игры
img/                ← картинки сайта; img/uploads/ — всё, что загружено через админку
admin/              ← админка (Decap CMS)
api/auth.js         ← вход в админку через GitHub (шаг 1)
api/callback.js     ← вход в админку через GitHub (шаг 2)
vercel.json         ← настройки Vercel (сжатие картинок, кэш)
```

Когда ты нажимаешь «Опубликовать» в админке, она сохраняет изменения в GitHub, а Vercel сам пересобирает сайт. Через 30–60 секунд изменения видны на сайте.

## Первичная настройка (один раз, ~15 минут)

### 1. GitHub — хранилище сайта
1. Зарегистрируйся на https://github.com (если ещё нет аккаунта).
2. Нажми **New repository** → назови `portfolio-site` → **Public** или **Private** → **Create repository**.
3. На странице репозитория нажми **uploading an existing file** и перетащи **всё содержимое** этой папки (не саму папку, а файлы и папки внутри). Внизу нажми **Commit changes**.

### 2. Vercel — хостинг
1. Зайди на https://vercel.com → **Sign up with GitHub**.
2. **Add New… → Project** → выбери репозиторий `portfolio-site` → **Deploy**. Настройки сборки не трогай, фреймворк: *Other*.
3. Через минуту сайт откроется по адресу вида `portfolio-site-xxxx.vercel.app`. Запиши этот адрес.

### 3. GitHub OAuth App — ключ для входа в админку
1. GitHub → аватар → **Settings → Developer settings → OAuth Apps → New OAuth App**.
2. Заполни:
   - **Application name:** `Портфолио — админка`
   - **Homepage URL:** `https://<твой-сайт>.vercel.app`
   - **Authorization callback URL:** `https://<твой-сайт>.vercel.app/api/callback`
3. **Register application** → скопируй **Client ID** → нажми **Generate a new client secret** и скопируй секрет (он показывается один раз).

### 4. Переменные в Vercel
Vercel → проект → **Settings → Environment Variables**, добавь две:

| Name | Value |
|---|---|
| `OAUTH_GITHUB_CLIENT_ID` | Client ID из шага 3 |
| `OAUTH_GITHUB_CLIENT_SECRET` | Client secret из шага 3 |

### 5. Две строки в `admin/config.yml`
На GitHub открой файл `admin/config.yml` → карандаш (Edit) → замени:
```yaml
repo: ИМЯ-НА-GITHUB/portfolio-site
base_url: https://ТВОЙ-САЙТ.vercel.app
```
на свои значения → **Commit changes**.

Потом в Vercel: **Deployments → … → Redeploy**, чтобы подхватились переменные из шага 4.

### 6. Проверка
Открой `https://<твой-сайт>.vercel.app/admin` → **Войти через GitHub** → разреши доступ. Готово.

## Как добавить работу

1. `/admin` → **Мои работы → Проекты**.
2. **Добавить проект** (новый появится сверху списка).
3. Заполни: название, категории (это фильтры на сайте), описание, обложку.
4. В блоке **Слайды** нажимай **Добавить слайд**, загружай картинки, при желании пиши подписи. Порядок меняется перетаскиванием.
5. Нажми **Опубликовать** → через минуту работа на сайте.

**Добавить слайды в готовый проект:** открой проект → **Слайды → Добавить слайд** → **Опубликовать**.
**Поменять порядок проектов:** перетаскивай их в списке. Как в списке, так и на сайте.
**Спрятать проект, не удаляя:** сними галочку «Показывать на сайте».
**Заглушки** («24 бренда косметики» и другие без картинок) можно просто удалять или заполнять своими работами. Проект без обложки и слайдов показывается как заглушка «скоро».

## Картинки
- Подойдут JPG, PNG, WEBP. Сайт сам уменьшает загруженные картинки (Vercel Image Optimization), но лучше не грузить файлы больше ~5 МБ.
- Обложка карточки — вертикальная 4:5. Если её нет, возьмётся первый слайд.

## Тексты
**Тексты сайта** в админке: обо мне, опыт (галочка «работаю здесь сейчас» включает плашку «сейчас играет»), образование, скиллы (с выбором иконки), услуги, контакты, текст финала игры.
Чтобы выделить слова в «Обо мне» розовым маркером, оберни их в `**две звёздочки**`.

## Свой домен
Vercel → проект → **Settings → Domains** → добавь домен и следуй подсказкам. Потом поменяй `base_url` в `admin/config.yml` и адреса в OAuth App на новый домен.
